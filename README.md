# AniCursor

AniCursor is a Linux cursor theme setup tool.

It helps users convert Windows cursor packs into Linux cursor themes,
map cursor files to standard cursor roles, and install and apply themes.

## Target

- Ubuntu 26.04 LTS
- GNOME
- Wayland
- GTK 4
- Python
- Bash
