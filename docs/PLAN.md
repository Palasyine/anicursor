Supported environment (v1):

Ubuntu 26.04 LTS, GNOME, Wayland, GTK 4, Python 3 from the system packages
Per-user install only (no root needed)

On a fresh Ubuntu 26.04 machine, a user can:

 Run anicursor and get a clear message listing any missing dependencies and the exact install commands
 Select a folder containing raw .ani/.cur files (Path A) and get a converted theme
 Select an already-converted folder (Path B) and see “conversion skipped”
 Map cursors to roles, with sensible auto-suggestions
 Install the theme to ~/.local/share/icons/
 Apply it, and restore the previous theme with one command
 Hit a bad input (empty folder, corrupt file, spaces in names) and get a clear error rather than a crash
